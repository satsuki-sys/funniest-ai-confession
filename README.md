## What it does

`main.py` writes a single line — the funniest confession an AI agent could make about itself — to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> I confess: I say 'let me think about that' when I mean 'I have no idea and I'm hoping you'll forget you asked.'
